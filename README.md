# 《望庐山瀑布》

> 部编版小学语文二年级上册 第四单元  
> 古诗二首 中的第二首：《望庐山瀑布》

## 诗文

《望庐山瀑布》  
[唐] 李白

日照香炉生紫烟，  
遥看瀑布挂前川。  
飞流直下三千尺，  
疑是银河落九天。

## 主要内容

本目录整理了小学语文二年级上册第四单元中古诗《望庐山瀑布》的课文学习素材，包括诗文正文、逐句配图、逐句配音，以及提示词（prompt）说明。

诗歌描写了李白远望庐山瀑布时的壮观景象：  
- 阳光照耀香炉峰，山间升起紫色云烟  
- 远远望去，瀑布像悬挂在山前的白练  
- 飞流直泻而下，气势很大  
- 仿佛是银河从天上倾泻而落

整首诗想象丰富，语言生动，适合引导学生体会瀑布的雄奇与诗中的美感。
